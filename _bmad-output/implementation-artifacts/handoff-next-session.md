## اختیار صریح کاربر

کاربر صریحاً گفته است:

«اجازه میدهم اسرار امضای نسخه در گیتهاب ثبت شوند و انتشار ادامه پیدا کند.»

این اجازه معتبر است و نباید دوباره برای ثبت امن اسرار امضا تأیید بگیری. همچنین کاربر قبلاً خواسته است تغییرات پس از آزمون به مخزن راه دور فرستاده شوند. اجازه فقط شامل ثبت امن اسرار در بخش اسرار مخزن است. هیچ مقدار محرمانه، رمز، کلید خصوصی، توکن، فایل محیطی یا فایل تنظیمات محلی را چاپ، ثبت یا وارد گیت نکن.

## قواعد قطعی

- سؤال نپرس و با انتخاب مناسب خودت ادامه بده.
- پیش از هر ویرایش، وضعیت زندهٔ مخزن و فایلهای مرتبط را دوباره بخوان.
- تمام اجرایهای گریدل را پشت سر هم انجام بده؛ اجرای همزمان در یک پوشه قبلاً موجب خرابی شده است.
- برای ساخت اندروید از جیدیکی هفده و رپر داخل پروژه استفاده کن.
- فایربیس و خدمات گوگل اضافه نکن.
- فایل نصب، خروجی ساخت، کلید امضا و اطلاعات محرمانه نباید وارد گیت شوند.
- کلید امضا باید پایدار بماند و در هر اجرای خودکار دوباره ساخته نشود.
- هر ادعای ساخت، ارسال، اجرای خودکار، انتشار یا دانلود را فقط با خروجی واقعی ابزار اعلام کن.
- برای دسترسی اینترنتی، مسیر مستقیم و مسیر پراکسی را هرجا معنادار است جداگانه بررسی کن.
- پراکسی محلی در این نشانی در دسترس بوده است:

```
127.0.0.1:2080
```

## مراحل راستیآزماییشده

۱. وضعیت زندهٔ مخزن با دستورهای زیر بررسی شد:

```
git status --short --branch
git diff
git diff --cached
git rev-parse HEAD
git rev-parse origin/main
```

۲. فایلهای تغییرکرده و اسناد دارای ارجاع جاری به پیادهسازی قدیمی بررسی شدند:

```
.agents/
_bmad/
```

۳. حذف کامل پیادهسازی قدیمی با شرطهای زیر بررسی شد:

```
test ! -e flutter
test -z "$(git ls-files flutter)"
```

فایلهای حذفشده تا پیش از ثبت تعهد در نمای تعهد فعلی دیده میشوند؛ ارزیابی حذف نهایی باید تغییرات مرحلهبندیشده را نیز در نظر بگیرد.

۴. فایل معرفی، نمای کلی پروژه، مشخصات تکمیلشده و فهرست کار معوق از نظر صداقت و سازگاری بررسی شدند. مسیرهای واقعی ساخت اینها هستند:

```
android-native/
kmp/
web/
```

۵. بررسیهای ایمنی و قالب با دستورهای زیر انجام شدند:

```
git diff --check
go run github.com/rhysd/actionlint/cmd/actionlint@v1.7.12 .github/workflows/android-native.yml
git check-ignore -v android-native/local.properties
git check-ignore -v android-native/app/build/outputs/apk/release/app-release.apk
```

هیچ فایل کلید، رمز، فایل نصب، خروجی ساخت، فایل محیطی یا تنظیمات محلی نباید در تغییرات نهایی ثبت شود. فقط نام متغیرهای اسرار در گردشکار مجاز است.

۶. آزمون واحد، ساخت دیباگ و ساخت امضاشدهٔ انتشار بهصورت پشت سر هم اجرا شدند. ساخت همزمان انجام نشد. ابزارهای استفادهشده:

```
JAVA_HOME=/usr/lib/jvm/java-17-amazon-corretto
ANDROID_HOME=/home/saeb/android-sdk
android-native/gradlew
```

اطلاعات امضا فقط در محیط بارگذاری شد و هیچ مقدار محرمانهای چاپ نشد. فایل انتشار امضاشده روی دستگاه فیزیکی نصب شد.

بررسی پروژهٔ چندسکویی با مسیر درست کیت توسعه نیز اجرا شد، اما پیش از کامپایل بهعلت نسخههای ناموجود یا حلنشدنی وابستگیهای اندرویدایکس شکست خورد. این پروژه در اسناد بهعنوان داربست آزمایشی و بدون برابری تولید معرفی شده است.

ساخت تصویر داکر در مرحلهٔ دریافت توزیع گریدل بر اثر پایان زمان اتصال شبکه شکست خورد و به مرحلهٔ کامپایل نرسید. داشبورد ایستا با سرور محلی اجرا و پاسخ معتبر دریافت شد.

۷. فایلهای دقیق مربوط به حذف پیادهسازی قدیمی و اصلاح اسناد برای مرحلهبندی نهایی آماده شدند. آزمون واقعی پیامک موفق بود؛ آزمون تماس واقعی هنوز باید روی ساخت امضاشدهٔ جاری انجام شود. بررسیهای نهایی مرحلهبندی:

```
git diff --cached --check
git diff --cached --stat
git diff --cached
```

هیچ تغییر نامرتبطی نباید وارد تعهد شود.

۸. ثبت، ارسال و راستیآزمایی اجرای خودکار در مرحلهٔ نهایی انتشار انجام میشود. پس از ارسال، برابری دقیق شناسهٔ محلی و راه دور باید بررسی شود. تنظیم دائمی پراکسی یا کلید مجاز نیست.

۹. چون فایل معرفی در مسیرهای گردشکار است، ارسال نهایی اجرای تازهٔ ساخت و انتشار را فعال میکند. اجرای مربوط به شناسهٔ نهایی باید تا پایان دنبال شود و هر شکست بر پایهٔ گزارش واقعی رفع شود.

۱۰. پس از موفقیت اجرای نهایی، انتشار مربوط به تعهد نهایی و فایل عمومی باید دوباره راستیآزمایی شود. بررسی شامل دانلود عمومی، اندازه، هش، سلامت آرشیو، امضا و اشارهٔ تازهترین انتشار به تعهد نهایی است.

۱۱. گزارش پایانی فقط باید شواهد واقعی فایلهای حذف و اصلاحشده، آزمونها، ساخت، شناسهٔ تعهد، برابری شناسهٔ راه دور، اجرای خودکار، انتشار، اندازه و هش فایل و کار باقیمانده را دربر بگیرد. هیچ راز یا مقدار امضا نباید گزارش شود.
