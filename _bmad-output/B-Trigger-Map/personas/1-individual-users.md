# Persona: Individual Users

## Summary
Tech-savvy individuals who value privacy and self-hosting, want reliable forwarding without Google services.

## Priority Reasoning
Primary users needing personal SMS/call forwarding to self-hosted server

## Positive Drivers
- Privacy
- Reliability
- Offline capability
- Customizability

## Negative Drivers
- Complex setup
- Battery drain
- Unreliable delivery

## Goals and Tasks
- Successfully forward SMS/calls
- Receive replies via SSE
- Configure via dashboard
